## Overview

Stardew Valley Love of Cooking Manager is a companion for the Love of Cooking SMAPI mod, tracking which cooking recipes have been learned, what ingredients each recipe requires, which shops sell required ingredients, and estimating the Cooking skill experience gained from cooking each recipe. It makes planning a cooking-focused Stardew Valley run efficient.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Stardew Valley Love of Cooking Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Recipe Tracker** | Tracks which Love of Cooking recipes have been learned so far |
| **Ingredient Sourcing** | Maps each recipe's ingredients to their shop or farm sources |
| **XP Calculator** | Estimates Cooking skill XP gained from each recipe |
| **Seasonal Planning** | Highlights recipes requiring seasonal crops grown this year |
